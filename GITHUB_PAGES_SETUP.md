# GitHub Pages Configuration Guide

## ✅ Seu site está pronto para GitHub Pages!

### 📋 Passos para Habilitar:

1. **Acesse as Configurações do Repositório:**
   - URL: https://github.com/erivelson82/Confirmar-Presen-a-/settings
   - Ou: Repositório → Settings

2. **Localize "Pages" na barra lateral esquerda**
   - Desça até encontrar a seção "Code and automation" → "Pages"

3. **Configure da seguinte forma:**
   - **Source**: Selecione `Deploy from a branch`
   - **Branch**: Selecione `main`
   - **Folder**: Selecione `/(root)`
   - **Clique em "Save"**

4. **Aguarde 1-2 minutos** enquanto o GitHub processa

5. **Seu site estará disponível em:**
   ```
   https://erivelson82.github.io/Confirmar-Presen-a-/
   ```
